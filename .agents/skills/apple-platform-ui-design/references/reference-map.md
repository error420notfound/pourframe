# HIG Reference Map

Use this map to select the smallest set of source files that can answer the task. The Markdown files in `hig/` are the supplied Apple Human Interface Guidelines snapshot.

## Core routing

For broad concept design, redesign, or audit, read:

- [Design principles](hig/design-principles.md)
- The relevant platform guide: [iOS](hig/designing-for-ios.md), [iPadOS](hig/designing-for-ipados.md), [macOS](hig/designing-for-macos.md), or [iPhone Duo](hig/designing-for-iphone-duo.md)
- [Layout](hig/layout.md)
- [Accessibility](hig/accessibility.md)

For a narrow question, read the target-platform guide plus only the topical references below.

## Common task bundles

| Task | Read these references |
| --- | --- |
| Mobile form with keyboard visible | Target platform, layout, entering data, text fields, virtual keyboards, scroll views, accessibility |
| iPad landscape workspace | iPadOS, layout, multitasking, sidebars, split views, toolbars, keyboards, pointing devices |
| iPhone Duo concept | iPhone Duo, layout, target interaction components, accessibility |
| Real-time monitoring interface | Target platform, layout, charting data, charts, gauges, progress indicators, feedback |
| Navigation redesign | Target platform, layout, tab bars or sidebars, toolbars, searching, modality |
| Image-generation brief | Target platform, design principles, layout, accessibility, typography, colour, materials, plus the interaction-specific components shown |
| Web or PWA on Apple devices | iOS or iPadOS, layout, accessibility, web views when embedded content is involved, plus task-specific patterns; translate guidance to web semantics |
